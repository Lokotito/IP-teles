## 🔗 URL del manifiesto

Utiliza la siguiente dirección para acceder a la lista de canales:

## 📺 ¿Cómo utilizar?

1. Abre **Kodi**.
2. Configura el complemento (PVR client) compatible con listas M3U.
3. Copia la dirección del manifiesto indicada arriba.
4. ¡Disfruta de la televisión en línea!

## ▶️ ¿Cómo abrir en Reproductor?

1. Abre **Reproductor** compatible con listas M3U (ejemplo VLC)
2. Descarga la lista M3U desde este enlace: <a href="master.m3u8">TV-LIST</a>
3. ¡Disfruta de la televisión en línea!
